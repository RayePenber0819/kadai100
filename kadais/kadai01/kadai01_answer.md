1. 間違ったコミットの修正
	- 課題: 「先ほどコミットした内容に誤りがあることに気づきました。正しい内容に修正して再度コミットしてください。」
  $ git commit --amend -m “ミスったよ”

2. 開発の履歴を見る
	- 課題: 「過去に実装した機能のコードを確認したいです。コミットログを表示し、特定のコミットまで戻って、その時点でのコードを確認してください。」
    commit log

3. ブランチを使った機能の開発
	- 課題: 「新しい機能を開発するために、別のブランチを作成してください。そのブランチで機能を実装し、テストが完了したらメインブランチにマージしてください。」
    git switch -c newbranch
    git add .
    git commit -m "新しい機能実装したよ"
    git push origin main
    ～テスト実行～
    git marge origin

4. 複数の開発者との共同作業
	- 課題: 「チームメンバーが作業したブランチをリモートリポジトリにプッシュしました。そのブランチをローカルに取得し、自分のブランチにマージしてください。」
    git pull origin othermenbersbranch

5. コミットの整理
	- 課題: 「過去数回のコミットが小さすぎると判断されました。これらのコミットをひとつにまとめて、コミットメッセージを修正してください。」
    git rebase -i HEAD~3
    まとめることによって削除したいコミットのpickをsに変更する
    コミットメッセージを編集

6. 作業中の変更の一時保存
	- 課題: 「現在の作業を一時的に保存し、別のブランチでバグ修正を行いたいです。作業中の変更を保存して、別のブランチに切り替えてください。」
    git stash
    git switch otherbranch
